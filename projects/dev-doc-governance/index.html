Documentation governance

dev-doc-governance

Composable checks for documentation structure, ADR indexes, local links, metadata, and decision references in engineering repositories.

View source and README on GitHub

Keep repository documentation consistent

As an engineering repository grows, ADR tables, document locations, and local references can drift. dev-doc-governance gives maintainers separate checks for the declared document tree, generated ADR and pitfall indexes, link integrity, required metadata, and stable decision references. It also checks links in project and package guidance files such as AGENTS.md. Use its read-only check in a review workflow to see what needs fixing before changing documentation.

At a glance

Who it helps
Maintainers who need documentation contracts that can be checked before a change lands.
First useful action
Run the read-only documentation check and review its actionable findings.
Scope
A repository toolset, not a hosted documentation platform.
