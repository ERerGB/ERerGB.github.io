Hacker

An agent skill for corpus-evaluated prompt improvement: diagnose failures, propose targeted mutations, and keep a regression gate.

View source and README on GitHub

Improve prompts with a regression gate

A prompt can fix one edge case while breaking several that previously worked. Hacker uses a labeled example corpus to score a proposed prompt mutation against the existing cases. It diagnoses failures, researches a targeted change, and records whether the scored cycle should be accepted or rolled back. This is useful for classifiers and other prompts with expected outputs. Supply real examples before optimizing; the skill cannot infer correctness from a persuasive prompt alone.

At a glance

Who it helps
Prompt and agent builders who have examples with expected results.
First useful action
Run one scored prompt iteration against a labeled corpus, then inspect the accept or rollback result.
Scope
A single invocation runs one scored mutation cycle; sustained loops need an external driver.
