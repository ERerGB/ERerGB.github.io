Agent skill governance

skills-auditor

Plan-first inventory, alignment, and verification of AI agent skills across Codex, Cursor, and Claude Code workspaces.

View source and README on GitHub

Review skill changes before applying them

A team can end up with different copies of the same AI skill in its Codex, Cursor, and Claude Code workspaces. skills-auditor inventories what is present, proposes a plan to align or integrate skills, waits for approval, and then verifies the result. The plan, receipt, and verification stages make a skill governance change reviewable. Start with a chat request for an audit; install or change skills only after reviewing the proposed scope.

At a glance

Who it helps
Teams maintaining a shared skill collection across several agent hosts.
First useful action
Request an audit, review the proposed plan, then approve any integration before changes are applied.
Scope
The audit does not certify skill safety or silently authorize changes.
For installation, examples, and the latest project status, read the GitHub repository.
