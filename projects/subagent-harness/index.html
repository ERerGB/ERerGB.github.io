subagent-harness

Validate one portable agent definition and build runtime-native subagent artifacts for Cursor, Codex, and Claude Code.

View source and README on GitHub

Build for several agent runtimes from one source

Define a subagent once in a portable .agent.md file. subagent-harness validates that source and builds artifacts for the runtimes you choose, including Cursor, Codex, and Claude Code. This helps teams keep a shared definition while each environment receives its own native output. The compatibility layer preserves visible differences between runtimes: it does not promise identical capabilities, and it does not run the agents it builds.

At a glance

Who it helps
Builders who maintain agent definitions for more than one runtime.
First useful action
Validate a .agent.md source and build the target runtime artifacts.
Scope
It builds definitions; it does not execute or sandbox agents.
For installation, examples, and the latest project status, read the GitHub repository.
