Conversation to EPUB

Folio

A Codex skill that turns selected conversations or notes into chaptered, versioned EPUB booklets and records e-reader delivery.

View source and README on GitHub

Make a conversation readable and revisable

Folio starts from a selected conversation or note series, organizes it into chapters, and produces a validated EPUB booklet. Later material can update the same booklet with a new version instead of creating an unrelated export. For an e-reader transfer, the workflow records the actual delivery stage and route; BOOXDrop on a local network is the observed automated adapter. Other devices depend on the available user tools and verification. Choose the source and reader when starting the task.

At a glance

Who it helps
Readers who want durable, revisable booklets from their conversations.
First useful action
Build and validate one EPUB from a selected conversation or note series.
Scope
Device delivery depends on the route; only the observed BOOXDrop local-network route has an automated adapter.
For installation, examples, and the latest project status, read the GitHub repository.
